# 记个账

安卓原生个人账本。记一笔时只需输入金额、选一个自建类型标签。支出可以直接点选场景和类型，例如「出差 · 晚餐」，账户也可留空。账本显示本月结余和最近流水。统计按周、月、年查看，周视图显示周一至周日的每日收支。资产账户余额可手动校准。

[下载最新签名 APK](https://github.com/daybreak430/WMM/releases/latest)

## 使用

- 底栏由左至右为「账本」「+」「统计」，蓝色记账按钮固定居中。点按三个按钮均有轻微触感反馈。点按标签直接切页，也可横拖选中的玻璃胶囊切换。
- 点「+」后记账页从底部滑入，右上角关闭按钮让整页向下退出。
- 流水列表按日期分组。时分可选，手动填写或从账单识别到的时间可在编辑流水时查看。
- 个人设置在账本页右上角。外观可直接切换「跟随系统」「浅色」「深色」。这里也可以从系统照片选择器上传头像、设置昵称、管理标签、配置模型、导出和恢复备份。
- 「个人设置 → 关于」显示当前安装版本，可直接打开 GitHub Releases。
- 如需联网报告，选 DeepSeek 或 MiniMax 国内站并保存对应 API Key。周报、月报、年报用平常话讲一个容易忽略的消费发现，再用少量数字解释。连续的可比记录能支持对支出惯性的判断。
- 统计页随所选期间展示支出类型、支出场景和收入类型的环形占比图。场景图以全部支出为分母，未标场景单列。点击场景或类型可查看对应流水。
- 本机会从跨天重复的记账时间、金额和备注学习分类习惯。信号充分时自动选中类型和场景，可手动覆盖。「个人设置 → 按位置推荐分类」可选择加入大致位置。位置范围仅存于本机，关闭时清除。
- 「个人设置 → AI 导入账单」支持图片、PDF、DOCX、CSV 和 TXT。识别结果会参考本机习惯。改完一笔后可核对并同步类似候选的分类，最后确认导入。
- 「个人设置 → 定时账单」可设每天、每周、每月或每年自动记一笔。首次日期决定重复日，短月按月末记账。系统延迟执行时会按原定日期补记，打开应用也会检查。删除定时账单会停止后续记账，已生成的流水保留。
- 「标签管理 → 配图标」可预览并应用图标建议，也可为类型和场景单独挑选图标、颜色。新建标签或场景时可在名称旁先配图标再保存。标签管理页和流水列表都会显示已配置的图标。标签仍可长按拖动排序。
- 个人设置在头像下方显示默认脱敏的净资产总额，可用眼睛按钮临时显示或隐藏。点击「资产」其余区域可维护账户，长按账户卡片可调整顺序。在「关联账户」中可为新流水设置默认账户，也能为单笔流水另选账户或不关联。
- 导出的 JSON 备份通过系统分享面板发送，文件未加密，可保留自定义排序、默认账户、标签图标和定时账单。支持恢复 v1 至 v7 备份。恢复会替换本机数据。API Key 和位置范围不包含在备份中。

## 构建

Android 8.0（API 26）起。使用 Android Studio 自带 JDK、Android SDK 37 及 Build Tools 36.0.0。安装 SDK 后打开仓库根目录，或设置 `JAVA_HOME` 和 `ANDROID_HOME` 后运行：

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
```

本机签名出包：在 macOS 运行 `./scripts/build-release.sh`，生成 `release/WMM-<版本>-release.apk`。脚本首次运行时创建项目专用签名密钥；密钥库位于 `~/Library/Application Support/WMM/signing`，密码存放在登录钥匙串。请保管好这两项，后续覆盖安装需要同一签名。调试包使用独立包名 `com.wmm.ledger.debug`。

每次 Android 更新都发布到 [WMM Releases](https://github.com/daybreak430/WMM/releases)。先推送构建对应的源码提交，再创建指向该提交的 `v<版本>` 标签并上传同名签名 APK。发布后从公开页面下载 APK，核对它与本机签名包的 SHA-256。
