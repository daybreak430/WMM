# 状态变化与统一动效

适用版本：0.13.6。实现集中于 `ui/LedgerMotion.kt`，不增加依赖，不改变数据模型。

## 节奏

| 状态变化 | 规则 |
| --- | --- |
| 进入／离开详情 | 260／160ms，位移为页面宽度的 1/10／1/20，方向表达层级 |
| 打开／关闭新建记账 | 从底部进入 320ms，向下退出 340ms，退出淡出延后 80ms |
| 选择、松手、尺寸变化 | 阻尼比 1、刚度 700 的弹簧，无反复振荡；新操作从当前值接续 |
| 按压 | 内部视觉缩至 0.975；外层点击区与读屏范围保持不变 |
| 颜色变化 | 120ms；不改变字体粗细、布局或点击语义 |
| 内容／金额／图标替换 | 180ms 轻量显现，不保留旧内容，不逐位计数、不制造虚构金额 |
| 弹窗 | 窗口负责 180ms 进入、120ms 离开；不叠加 Compose 缩放 |
| 列表增删重排 | 稳定业务 key；120ms 淡入淡出与统一弹簧定位；滚动不做逐行入场 |
| 付款识别浮层 | 180ms 从上方 8dp 显现，普通收起 120ms；安全性移除立即执行 |

时长曲线使用 `(0.2, 0.8, 0.2, 1)`；弹窗窗口动画使用 Android 标准减速／加速曲线。底栏速度形变沿用高刚度跟随弹簧，位置由拖动位移直接驱动。

## 按状态变化审查

| 变化 | 涉及流程与最终处理 |
| --- | --- |
| 页面出现、消失和返回 | 首页、统计、设置、搜索、问答、账单导入、标签、账户、定时账单、退款、转账与核对共用页面转场；新建保留独立底部方向。旧页面立即屏蔽交互。 |
| 标签页或期间变更 | 当前内容和语义立即替换，底栏胶囊与分段选择背景交代来源和目标；页面内容轻量显现，不同时保留两份可点击筛选结果。 |
| 选中、取消选中 | 收支、转账、周月年、外观和标签管理分段共用滑动底板；标签、场景、图标／颜色选择与周趋势高亮使用统一颜色过渡。复选框、开关和文本焦点沿用 Material 原生动效。 |
| 内容变多、变少或换位 | 类型／场景展开收起与问答结果使用局部尺寸动效；统计更多分类、流水、待核对记录、账户、定时账单和图标列表使用稳定 key 的惰性列表过渡。拖动本体直接跟手，周围项目让位。 |
| 金额、日期、账户与图标更新 | 共用 AmountText、EntryMetaButton、EntryDetailRow、SettingsRow 与图标入口处理；净资产隐藏后旧金额立即从合成树移除；金额自动字号和单行约束保留。 |
| 输入和系统键盘切换 | 数字输入即时显示，保留表达式计算原有逻辑，不对每次按键的数字做滚动动画。键盘避让由系统 inset 驱动，不叠加高度动画；横竖屏结构立即按窗口尺寸布局。 |
| 加载、完成、失败、重试 | 导入识别／预览切换、主操作标题和问答加载／答案／错误过渡统一；问答容器局部变高。转圈、checkbox 和 switch 沿用原生实现；Snackbar 沿用 Material 的进退场。退款校验错误出现／消失使用统一展开收起。 |
| 弹窗提交、取消和系统返回 | 共用窗口级退场；继续使用原业务提交回调，不为等待动画延迟保存或重复提交。删除／恢复等后果提示保留。 |
| 头像与图片变化 | 保留原图片解码缓存和裁切；不引入整屏图片交叉合成。头像替换直接显示，避免保存多份头像位图。 |
| 悬停和禁用 | 原生 Material／clickable 的悬停、焦点、涟漪与禁用语义保留；没有鼠标悬停业务状态的控件不新增悬停行为。 |
| 锁屏、关闭识别与候选替换 | 浮层立即移除，无动画等待；普通自动收起／稍后使用短退场，退场期间关闭操作和读屏。 |

## 减少动态效果和性能边界

- Theme 监听 `Settings.Global.ANIMATOR_DURATION_SCALE`。为 0 时自定义状态变化直接就位；Compose 动画同时遵守系统时长缩放。弹窗受系统窗口动画缩放控制，animator 关闭时也禁用自定义窗口动画。浮层通过 `ValueAnimator.areAnimatorsEnabled()` 决定是否播放。
- 按压、透明度、底栏位置和图表比例尽量在绘制／定位阶段读取状态；不添加无限装饰动效、逐条错峰或整棵长列表尺寸动画。
- 列表只维护可见项动画；对整张账本的统计计算继续复用已有 remember，不在动画回调里查库或重新汇总。
- 同一时刻只保留当前金额／图标／筛选语义。可折叠内容虽然有可见离场阶段，但在目标状态切换时就禁止旧控件触控。
- `MotionUiTest` 覆盖动画未结束时的触控／语义、快速反向切换、隐藏金额与关闭动画。`MotionPerformanceTest` 使用 1,200 笔合成流水，在同一设备上记录 FrameMetrics 总耗时和测量布局耗时，便于同版本和前后版本复测；不把模拟器结果视为真机 60／120Hz 保证。
