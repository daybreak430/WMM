# WMM UI 美化 Design

状态：已确认。范围见 [PRD](prd.md) 的 P01 和 P02。[样式卡](style-card.html) 用该文档的日间、夜间参数渲染。

## 1. 方向

清透、规整、克制。淡蓝从屏幕顶部渐隐，首页大数字左对齐。总览卡用白色细边和偏冷的反光形成层次，亮蓝集中在主要操作与选中态。

## 2. 参考

## 4. 文字

字体顺序为 Roboto、Noto Sans SC、PingFang SC、系统无衬线。Android 采用系统 Roboto 和中文回退。以下为字号／行高／字重，Demo 用 CSS px，Android 文字按对应 sp 实现并允许系统缩放。

| 用途 | 数值 | 补充 |
|---|---|---|
| 首页结余 | 44／50／650 | 字距 −2.0px，左对齐 |
| 录入金额 | 46／54／650 | 字距 −2.0px，居中；币种符号 28／34／600 |
| 页面标题 | 22／28／650 | 账本标题左对齐；录入标题居中 |
| 区块标题 | 18／24／650 | 标签等独立区块 |
| 流水标签与金额 | 15／21／600 | 标签单行省略；金额等宽数字并右对齐 |
| 汇总子金额 | 15／20／650 | 按列左对齐 |
| 正文与按钮 | 14／20／500；主按钮 14／20／650 | 中文正文保持足够行高 |
| 次要文字与小标签 | 12／17／500 | 日期、备注、月份 |

金额启用 `tabular-nums lining-nums`。超长金额缩小到可读的 30px 下限后再处理溢出。资料、日期和流水备注使用较低字重。

## 5. 间距、形状与线条

- 4px 栅格；页面左右 20px，窄于 360px 时用 16px。区块间距 16–20px，流水组之间 12px。
- 总览卡内边距 20px、圆角 24px，阴影 `0 8px 22px rgba(var(--shadow-rgb), .08)`。普通卡片圆角 18px、内边距 14px、1px 描边。
- 流水行最小高度 60px，横向间距 10px；图标底 36 × 36、圆角 11px。列表手势区覆盖整行。
- 主按钮高 50px，圆角 14px。标签高 34px、圆角 10px；两段切换高 44px、圆角 14px，选中片圆角 11px。
- 圆形图标按钮外观 40px，实际页面触控区至少 44px。标签触控区至少 44px，可用透明的上下留白扩展。
- 提示与弹层阴影 `0 12px 32px rgba(var(--shadow-rgb), .18)`，弹层圆角 22px。

## 6. 图标与图片

使用项目已有的 Lucide 资源。规范画布 24 × 24、笔画 2、圆端点和圆拐角。导航与工具栏显示 20px，流水方向与辅助图标显示 16–18px。使用图标表达入口和方向，本轮背景、卡面和数字用色彩及排版建立质感。

## 7. 组件

| 组件 | 处理 |
|---|---|
| 主按钮 | 蓝色实心、`--on-blue` 文字；禁用用 `--disabled`。首页与录入均靠底，离侧边 20px |
| 次要入口 | 蓝色文字链接或中性色描边；危险操作用 `--danger` 并保留确认弹层 |
| 总览卡 | 先放月份、标签与左对齐余额，1px 细线下并排收入与支出。左侧各级文字共用同一条基线方向 |
| 流水组 | 总览下直接接日期分组，不设额外标题或统计跳转；日期在组外、白卡在组内，行内分隔线避开图标，金额列右侧保持同一边线 |
| 每日小计 | 日期 14／20／500 在左侧，收支作为一个右对齐的信息组，间距 14dp。标签 11sp 常规字重，金额 13／20／600 并启用等宽数字；收入品牌蓝，支出中性色。组标题上留 16dp、下留 8dp，窄屏或大字号时按完整金额换行 |
| 标签 | 未选用白面细边，选中用浅蓝底和蓝字，长文字超出时换行排列 |
| 表单 | 金额在淡蓝到白的背景上，用一条细线收尾。账户、日期和备注在其下用统一表面，错误提示紧贴金额 |
| 导航 | 三项等宽，选中图标放在浅蓝底；图标与名称垂直排列 |
| 空状态 | 总览金额为零；「还没有流水」保持简洁，主按钮位置稳定 |
| 键盘 | 模拟键盘使用 `--keyboard` 底板和 `--surface` 键帽，三列四行，键最小高 36px，间距 6px。真机沿用系统键盘 |

## 8. 动效

页面过渡 220ms ease-out，弹层 260ms ease-out。按下缩放至 0.98，持续 100ms。启用减少动态效果时，过渡缩至 0ms。保存后保留短暂文字反馈。

## 9. 设备与演示

- 设计基准 393px 宽、836px 高；Android 状态栏和底部手势区采用系统 inset。桌面样式卡示意上方 26px、下方 16px。
- 桌面样式卡并排对照两页，并提供浅色、深色切换。Demo 采用三栏演示布局。窄屏采用单列，Demo 隐藏演示侧栏并使用系统输入法。
- 演示壳用 `--canvas`，手机画面投影用 `0 16px 36px rgba(var(--shadow-rgb), .10)`。预览内的金额、流水和时间使用 PRD 示例。

## 10. 页面

- **P01 账本。** 顶部标题和个人设置下放总览卡，结余左对齐。其下为 60px 行高的日期分组流水。393px 宽的正常字号首屏目标为 3–4 条完整流水。
- **P02 记一笔／编辑流水。** 顶部居中标题，下方依次放类型切换、金额、标签和辅助字段。显示数字键盘时保存按钮位于键盘上方，内容区域可滚动。编辑态标题为「编辑流水」，右上为删除入口。

## 11. 禁止清单

绿色主题、黑色主按钮、描边厚重的卡片、装饰性的视觉噪声、随意混用图标、重复说明文案。
