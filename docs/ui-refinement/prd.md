# WMM UI 美化 PRD（Demo 版）

状态：已确认。基线：Android 原生 WMM v0.2.1。

## 1. 一句话

为日常记账的个人用户打磨 WMM 的首页和录入页，让余额、流水和新账金额在手机上清楚好读，页面在空账本、真实金额和键盘弹出时都呈现一致的视觉质感。

## 2. 观众与演示

- 观众与场合：产品本人进行视觉评审，侧重美观度、排版和组件质感。
- 时间与设备：约 3 分钟。电脑用浏览器看演示，手机可直接打开窄屏版体验。
- 交付顺序：确认 PRD → 结合现有参考图确定视觉与样式卡 → 验收单文件离线 Demo → 按确认稿实现 Android 界面并验证安装包。

## 3. 核心场景

| 场景 | 触发 | 期望结果 |
|---|---|---|
| 看本月收支和最近流水 | 打开账本 | 视觉焦点明确，结余、收入和支出各有清楚的层级，流水金额对齐 |
| 快速记支出 | 点「记一笔」 | 金额立即可输入；选中标签后可以保存，返回首页即看到新流水和更新后的结余 |
| 看一笔旧账 | 点指定流水 | 进入同一种录入布局，能查看原金额、时间和标签，修改后可存回原记录 |

## 4. 演示高光

1. 同一屏展示本月总览和日期分组的真实感流水，用大小金额、较长标签和备注检验数字与文字的排版。
2. 从首页进入录入页，在数字键盘弹出时看清主要信息。保存后回到首页，体验新流水入列及结余更新。

## 5. 页面

| ID | 页面 | 入口 | 主要元素 | 验收状态 |
|---|---|---|---|---|
| P01 | 账本首页 | App 默认页；记账完成或返回 | 账本标题、设置入口、本月收支总览、最近流水、收支统计入口、蓝色「记一笔」、底部导航 | 有流水、无流水、保存后 |
| P02 | 记一笔 / 编辑流水 | P01「记一笔」；点一条流水 | 返回、收支类型、金额、标签、账户、日期时间、备注、保存；编辑态显示删除 | 默认支出、数字键盘弹出、无标签、金额无效、可保存、编辑态 |

## 6. 页面详情

### P01 账本首页

- 可重排总览与流水的版面。「记一笔」、设置、统计和底部导航保留现有入口和用途。
- 本月结余等于本月收入减本月支出。流水按账目日期分组并倒序展示，主行显示标签和带方向的金额，次行显示时间、已关联账户和已有备注。
- 点「记一笔」进入 P02 新建态。点流水进入 P02 编辑态。统计、资产和设置入口在 Demo 中给出「此页面在 Android 正式版中可打开」提示。
- 首次使用的空账本显示 ¥0.00 和「还没有流水」，记一笔入口始终可用。

### P02 记一笔 / 编辑流水

- 保持「首页进入 → 输入金额 → 选标签 → 保存」的操作顺序。新建时默认支出、当前时间，聚焦金额。编辑时回填已有数据，保留返回和删除入口。
- 支出和收入各有一套自建标签。标签必须选一个，可用「新建标签」当场创建并选中。切换收支时清空当前已选标签。
- 账户、日期时间和备注收在金额与标签下方。账户允许「不关联」，日期时间默认当前值，备注选填。
- 金额必须大于零，最多两位小数。金额无效时提示「请输入有效金额，最多两位小数。」金额有效且选了标签才能保存。保存后回 P01，编辑同一笔时更新原记录。删除先显示确认框，确认后回 P01 并更新合计。
- 桌面 Demo 用模拟数字键盘展示键盘占位，也可输入数字；手机用系统数字键盘。键盘弹出时页面可滚动，保存按钮可达。

## 8. 模式、文案与视觉约束

- 单一用户模式。桌面演示侧栏提供步骤、空账本和重置，窄屏显示 App 本体。支持浅色和深色，文案使用简体中文。
- 文案简短直白，例如「本月结余」「记一笔」「保存流水」。演示场景注明「样例数据」，保存后短暂提示「已保存」。
- 已确认的视觉延续项为冷白底、蓝色主按钮、Lucide 图标。样式卡集中比较金额字形与字重、白色卡面与边缘、列表密度、空白留量和键盘弹出后的视觉层次。具体设计参数在 Design 阶段确认。
- 内容采用示例流水、Lucide 和系统字形，无需人物照片、装饰插图或声音。

## 10. 本轮边界与模拟标注

统计、资产和设置沿用 Android 现有实现，独立页面留待后续。首轮视觉验收以 P01 和 P02 为准。

Demo 中选标签、输入、保存、修改、删除和收支计算都可实际操作。流水、账户、演示时钟和桌面数字键盘均为模拟，操作只保存在当前页面会话。最终 Android 版本接回现有的记账和本地存储。
